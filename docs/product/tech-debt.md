## フォントの暫定対応

> Supporting note: この文書はフォント関連の技術的負債に触る場合だけ参照する補助資料である。
> 現在状態は `docs/product/current-status.md` を正とする。

現在の状態:
- 現在のフォント設定は、システムフォールバックフォントに基づく暫定対応になっている
- Vercel 本番ビルドを安定させるため、`next/font/google` はいったん撤去している
- フォント指定自体は `app/layout.tsx` の CSS 変数で行っているが、実際の描画結果は各端末に入っているフォントに依存する

現在の課題:
- OS やブラウザによっては文字が意図より細く見えることがある
- macOS、Windows、モバイル環境で見た目の一貫性が不足している
- 現状はタイポグラフィ品質よりもビルド安定性を優先した状態になっている

恒久対応の方針:
- 暫定構成を、`next/font/local` を使った self-hosted フォント構成へ置き換える
- フォントアセットはリポジトリ内に保持する
- フォント制御は `--font-sans` と `--font-mono` に集約する
- ビルド時・実行時の外部フォント取得への依存をなくす
