# 外部通知レビュー記録

このファイルには、外部通知のレビュー結果を日付ごとに記録する。

記録するのは要約と判断のみとし、メール本文全文は保存しない。

## 記録ルール

- メール本文全文は貼らない
- URL、token、秘密情報は必要に応じて伏せる
- 判断の根拠は簡潔に残す
- 承認前の段階では、実装内容ではなく判断結果を中心に書く

## テンプレート

```md
## [YYYY-MM-DD] 外部通知レビュー

### 1件目
- 送信元:
- 件名:
- サービス:
- 重要度:
  - 高 / 中 / 低
- 通知の要点:
- Bloomlog への影響範囲:
  - 認証 / デプロイ / DB / 環境変数 / 課金 / ドメイン / GitHub運用 / 不明
- 必要な可能性がある対応:
  - コード変更 / dashboard 設定変更 / migration の可能性 / 対応不要 / 判断保留
- 根拠:
- 不明点:
- 人間承認待ち事項:
```
