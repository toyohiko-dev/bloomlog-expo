# 外部通知レビュー状態管理

このファイルでは、外部通知レビューの状態を一覧で管理する。

メール本文全文は保存せず、状態管理に必要な最小限の情報だけを記録する。

## 状態定義

- 新規
- 分析済み
- 承認待ち
- 対応不要
- 判断保留
- 実装依頼準備完了
- 対応済み

## 管理テンプレート

| 記録日 | サービス | 件名要約 | 重要度 | 影響範囲 | 現在の状態 | 次の確認者 | 次アクション | 備考 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| YYYY-MM-DD | Supabase | 例: 認証設定見直し通知 | 高 | 認証 | 新規 | 自分 | 本文をレビューする | |
| YYYY-MM-DD | Vercel | 例: ドメイン設定確認通知 | 中 | ドメイン | 分析済み | 自分 | 承認要否を判断する | |
| YYYY-MM-DD | GitHub | 例: セキュリティ通知 | 高 | GitHub運用 | 承認待ち | 自分 | 対応方針を決める | |

## 運用メモ

- `件名要約` には本文全文ではなく短い説明だけを書く
- `影響範囲` は `認証 / デプロイ / DB / 環境変数 / 課金 / ドメイン / GitHub運用 / 不明` を基本とする
- `現在の状態` は上の状態定義から選ぶ
- 実装や設定変更に進むのは `実装依頼準備完了` になってからにする
